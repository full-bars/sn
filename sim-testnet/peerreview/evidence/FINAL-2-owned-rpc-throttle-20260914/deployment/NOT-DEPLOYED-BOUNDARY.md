# Deployment boundary

The reviewable deployment handoff identifies a narrow future nginx rollout path. This evidence bundle records no deployment, SSH, host configuration read, nginx reload, node restart, public-RPC access, or native retry beyond the closed second refusal.

Deployment evidence needed later includes an authorized host identity, preserved live configuration and hash, local nginx syntax-check exit, installed hash, reload/service result, and direct post-rollout reads. The full-host runner remains outside this bounded source qualification.
