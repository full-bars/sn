# Handoff

This is an external, public-safe, closed qualification bundle. It supports review of the deterministic root cause, adjacent controls, exact selected membership, and source/binary/dependency fences. It does not authorize a source change, test, build, native operation, RPC call, or publication.

The causal patch is intentionally non-candidate material. Its expected failure must remain labeled causal. The original native refusal must remain labeled exit 1 before application.
