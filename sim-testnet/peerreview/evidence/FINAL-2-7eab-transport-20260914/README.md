# 7eab transport refusal evidence

This external bundle records the first closed 7eab native-apply refusal and the closed, read-only transport observations used to bound its diagnosis. It is intended for peer review and contains derived public-safe records plus hashes of their closed origins.

The transport refusal is retained as a failure. It does not identify a specific rejected HTTP request, a source defect, or a completed retry. The live retry is excluded.
