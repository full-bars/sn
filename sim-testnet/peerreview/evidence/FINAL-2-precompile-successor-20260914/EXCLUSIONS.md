# Exclusions

Not copied: binaries, Go/module caches, raw test2json events, stdout/stderr, command launchers, temporary fixtures, private plans, configuration contents, keys, signed receipts, RLP, journals, native/RPC/live material, release-lock material, and full source checkouts.

The bundle retains only public-safe patch text that passed a marker scan, source and binary hashes, compiled memberships, synthetic per-test outcome tables, concise results, source identities, and hashes of retained raw records.
