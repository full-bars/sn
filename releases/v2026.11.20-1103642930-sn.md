# v2026.11.20-1103642930-sn

**Released:** 2026-11-20.

Previous release: [v2026.11.15-1099306820-sn](https://github.com/full-bars/sn/releases/tag/v2026.11.15-1099306820-sn).

This release hides proxy credentials everywhere the miner prints or exports a proxy. It adds the `urnet-tools top` dashboard features of the other fork lines, UDP port 53 setup for the extender, per-carrier extender traffic and live carrier settings. It also fixes a hotswap abort on the provider key lock and stops a refused gossip stream from closing its whole session.

Update and restart. The hotswap fix is in the old process, so the first update that carries it still needs a restart.

Legend: **[redeploy]** needs the new provider, tool or container image. **[installer]** needs the updated installer or script. **[no redeploy]** covers documentation, CI and tests.

## Quick start

Already running a provider? Update in place:

```sh
urnet-tools update
```

Install on Linux or Alpine:

```sh
curl -fSsL https://raw.githubusercontent.com/full-bars/sn/refs/heads/main/scripts/Provider_Install_Linux.sh | sh
```

Install on macOS:

```sh
curl -fSsL https://raw.githubusercontent.com/full-bars/sn/refs/heads/main/scripts/Provider_Install_Mac.sh | sh -s -- install
```

Install on Windows in PowerShell. Windows Defender can flag the one-line form as a false positive, because the script downloads and unpacks a program. The safer way has two steps. Download the script, read it, then run it from disk:

```powershell
irm https://raw.githubusercontent.com/full-bars/sn/refs/heads/main/scripts/Provider_Install_Win32.ps1 -OutFile "$env:TEMP\install-win.ps1"
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:TEMP\install-win.ps1"
```

The Installation guide lists the Defender labels you may see and what to do about them.

On FreeBSD, download the installer and run it with a non-root service account selected:

```sh
fetch -qo urnet-install.sh https://raw.githubusercontent.com/full-bars/sn/refs/heads/main/scripts/Provider_Install_FreeBSD.sh
sudo sh urnet-install.sh install
```

OpenBSD support is experimental. The installer and the service have not run on an OpenBSD host. Durable client registration is unavailable there. Do not deploy OpenBSD providers to production yet.

On OpenBSD, the installer needs `jq` or `python3` to read the release metadata. Install `jq`, download the installer and run it with an existing non-root service account (replace `urnet` with its name):

```sh
doas pkg_add jq
ftp -o urnet-install.sh https://raw.githubusercontent.com/full-bars/sn/refs/heads/main/scripts/Provider_Install_OpenBSD.sh
doas env SERVICE_USER_OVERRIDE=urnet sh urnet-install.sh install
```

The installer does not sign the provider in. Sign in as the service account with a single-use auth code from https://ur.io, then restart the service. The OpenBSD guide has the exact commands.

Start a new provider container:

```sh
docker run -d --name urnetwork --restart unless-stopped \
  -e URNETWORK_AUTH_CODE=YOUR_AUTH_CODE_HERE \
  -e ALLOW_CLIENT_REGISTRATION=Y \
  -v urnetwork_config:/root/.urnetwork \
  ghcr.io/full-bars/sn:latest
```

Auth codes are single-use. Keep the state volume. If an existing identity is missing, restore its original volume instead of authorizing a replacement. For optional extender ports, see the [extender guide](https://github.com/full-bars/sn/wiki/Extender).

## What changed

### Security

- **Proxy credentials stay out of output. [redeploy]** Proxy audit lines, rejected input, URL errors, admission and UDP diagnostics, traffic state, metrics labels, `proxy ids` and the control socket no longer print a proxy user, a password or a fragment of either. A proxy host that looks like a credential (for example `user:pass@host` or `[user:pass]:1080`) is refused. An IPv6 host with a zone id is also refused. Proxy configuration files are written with owner-only permissions. ([1c3a11a](https://github.com/full-bars/sn/commit/1c3a11a2d31291e1eea488ee9251f50b667d2514), [e47c2cb](https://github.com/full-bars/sn/commit/e47c2cb79d4963d5bb039caf6d8b8fd2f73ade44), [a86593b](https://github.com/full-bars/sn/commit/a86593b7cb58a43dba721760095772292c553585))

### Fixed

- **A hotswap on a miner node no longer aborts on the provider key lock. [redeploy]** The new process opens the provider key right after the takeover message, and the old process still held the lock, so the new process exited with `startup_recovery_required`. The old process now releases the lock when it sends the takeover message and takes it back if the handoff aborts. ([4f7763c](https://github.com/full-bars/sn/commit/4f7763cc8c94aab24a79cd837789778e3627ee93))
- **A refused gossip stream no longer closes its yamux session. [redeploy]** The patched yamux module resets the refused stream when its memory reservation fails and keeps the session open. A refused duplicate stream id goes to the protocol error path. ([a014d0f](https://github.com/full-bars/sn/commit/a014d0f8add058b0ea17c1b6313c6acb8115691b), [713c84b](https://github.com/full-bars/sn/commit/713c84bc25d04725ce30591f76917bb52e111f04))
- **`urnet-tools top` no longer opens on a stopped provider. [redeploy]** Stopped providers are left out of the default list and the Tab cycle. `--all` shows them again. A provider named on the command line is kept even if it is stopped. ([2a85007](https://github.com/full-bars/sn/commit/2a850074961f000a5507ca260635fcf03123b39e))
- **`urnet-tools top` counts every client that is not post-quantum as classical, keeps the Extender box above Internals at every height, and adds one graph column per refresh at fast intervals. [redeploy]** ([ce0b80b](https://github.com/full-bars/sn/commit/ce0b80b55d6a3d230e11f3f4cd43095d37d2cd9f), [638c90b](https://github.com/full-bars/sn/commit/638c90b716962422299f8fd91afb1bdcc65f09df), [f6b273c](https://github.com/full-bars/sn/commit/f6b273c33c6f7d8abe92a5ae7afa7796738a0d59))
- **The proxy audit status is reported through the control socket. [redeploy]** It shows the last completed audit tick. ([3c682b0](https://github.com/full-bars/sn/commit/3c682b055b9294cb72856817f16699e2d411e51c), [2ef2482](https://github.com/full-bars/sn/commit/2ef2482c61ab059ed3439b1391f7c020348f6a3f))
- **A start after a systemd scan timeout no longer fails. [redeploy]** ([a45cf7b](https://github.com/full-bars/sn/commit/a45cf7b845dd7f15924ac4f9a62a6f8927c5b27a))

### Added

- **UDP port 53 for the extender. [installer] [redeploy]** `urnet-tools extender setup` offers to lower the sysctl port threshold to 53 as an explicit opt-in. The default stays 443. `top` and `urnet-tools extender status` show the UDP 53 status and the reason when it is off. Setup refuses to run without consent in non-interactive mode. ([736104c](https://github.com/full-bars/sn/commit/736104cec465ec9e8caf7691c3d9e980f222e194), [ac3552a](https://github.com/full-bars/sn/commit/ac3552a9f39b6c56b3fb3d9011d5d115a12554f6))
- **Live extender controls. [redeploy]** `urnet-tools extender on|off` sets the direct slot extender role live and saves it. The role is on by default. The UDP carriers can also be set live. A carrier change applies without a restart and a failed restart rolls back. ([da9481e](https://github.com/full-bars/sn/commit/da9481e10b41999a2e35eea1dcaea202de86c2d3), [8e267f9](https://github.com/full-bars/sn/commit/8e267f926300986658deecd0565690774e031383), [a8e73d3](https://github.com/full-bars/sn/commit/a8e73d30e11a65c2245d575160a6f4bae77d744b))
- **Traffic the extender relays, per carrier. [redeploy]** The extender counts the bytes it relays on `tcp-443`, `udp-443`, `udp-4053` and `udp-53`, on each side, with the rate, the relayed connections and a minute history. `urnet-tools extender status` prints a `Traffic relayed` table, `top` shows one row per carrier in its Extender box, and `/metrics` exports `urnet_extender_carrier_bytes_total{carrier,direction}` and `urnet_extender_carrier_connections{carrier}`. These are bytes this extender relayed. They are not earnings. ([cdf5365](https://github.com/full-bars/sn/commit/cdf53652567810327c4a55ff3b2ea672f068cfd9))
- **`urnet-tools top` has interactive diagnostics. [redeploy]** Resize panels with the mouse, inspect proxy health in a grid, and open alerts, resource gauges and carrier details. The Events panel filters and groups repeated entries. Press `t` to cycle the graph history (longer windows are added) and `o` to compare providers. Press `u` to switch byte labels between binary units (KiB, MiB, GiB) and decimal units (kB, MB, GB). `--copy` saves the final screen as text and `--plain` uses ASCII box characters. Accessible themes add a colorblind set of colors and symbols. The layout adapts to the terminal size. The glow tracks are configurable. ([8177508](https://github.com/full-bars/sn/commit/81775087d53ec13ddd90f8fee995e70c74ce2924), [130438d](https://github.com/full-bars/sn/commit/130438dce3d9a6b2ce1ce7eb4bbf932c24f54880), [2bc43cd](https://github.com/full-bars/sn/commit/2bc43cdaeecb88cdffc424b0e45fdad2fff805d6))
- **`top` shows a proxy's address and explains the heatmap. [redeploy]** Hover over or click a proxy cell to see its address, health and traffic. The miner reports proxy cells and their detail feeds, interface counters, and thread and swap resources. `urnet-tools top` also runs inside the container image, where `urnet-docker top` forwards terminal color settings. ([3e14c4b](https://github.com/full-bars/sn/commit/3e14c4bfe02e1564ae6990c7663c1d7c82a97d43), [3350665](https://github.com/full-bars/sn/commit/3350665071b3ed596b1a05914d60bcf32d2de749), [596d446](https://github.com/full-bars/sn/commit/596d4467117b0e4cb1ea8be01e5cd1c4f3614cac))
- **The container image and release archives ship license texts. [redeploy]** ([20d5423](https://github.com/full-bars/sn/commit/20d5423439fc709c75b01e75c7f66ae483003565))
