# v2026.11.1-1087127390-sn

Released 2026-11-01

## Quick start

> [!TIP]
> **Already running a provider?** Update in place - no reinstall, no new auth code:
> ```bash
> urnet-tools update
> ```

### Install a provider

```bash
# Linux (also Alpine and OpenRC, from a root shell)
curl -fSsL https://raw.githubusercontent.com/full-bars/sn/refs/heads/main/scripts/Provider_Install_Linux.sh | sh

# macOS
curl -fSsL https://raw.githubusercontent.com/full-bars/sn/refs/heads/main/scripts/Provider_Install_Mac.sh | sh -s -- install
```

```powershell
# Windows (PowerShell)
irm https://raw.githubusercontent.com/full-bars/sn/refs/heads/main/scripts/Provider_Install_Win32.ps1 | iex
```

FreeBSD is a two-step install because the installer runs with `sudo` and resolves the release tag before fetching:

```sh
fetch -qo urnet-install.sh https://raw.githubusercontent.com/full-bars/sn/refs/heads/main/scripts/Provider_Install_FreeBSD.sh
sudo sh urnet-install.sh install
```

Then authenticate once and load your proxies:

```bash
urnetwork auth
urnet-tools proxy add ~/proxies.txt
urnet-tools proxy refresh
urnet-tools status
```

> [!WARNING]
> Windows Defender flags the unsigned binaries and the PowerShell one-liner. The workaround is on the [Installation page](https://github.com/full-bars/sn/blob/main/docs/Installation.md).

### Run the container

```bash
docker run -d \
  --name=meso-miner \
  --pull=always \
  --restart=unless-stopped \
  --cap-add=NET_ADMIN \
  --cap-add=NET_RAW \
  --sysctl net.ipv4.ip_forward=1 \
  -e URNETWORK_AUTH_CODE='YOUR_AUTH_CODE_HERE' \
  -e HOST_HOSTNAME=$(hostname) \
  -v meso_miner_data:/root/.urnetwork \
  -v /path/to/proxy.txt:/app/proxy.txt \
  ghcr.io/full-bars/sn:latest
```

One image: `:latest` carries `urnet-tools` and `urnet-docker`. `URNETWORK_AUTH_CODE` is the variable the image reads; when it is set the auth-code path is selected on its own, so `BUILD` is not needed. The `:miner` image runs the same binary with a different entrypoint and is being retired.

> [!CAUTION]
> Auth codes are single-use. The token is saved to the `meso_miner_data` volume on first run, so keep that volume - without it you need a new auth code.

## What changed

## Network

**Exits without IPv6 stop costing a dial timeout** [redeploy]. A SOCKS exit that cannot reach IPv6 only shows it by letting an IPv6 dial hang until the timeout, and the host's own route check cannot see it. `connect` now keeps a verdict per proxy carrier: after three consecutive IPv6 dial failures through one carrier it refuses IPv6 through that carrier for 15 minutes, so dials go straight to IPv4, then lets one probe through to re-test. No carrier's verdict touches another carrier or the host, and exits that can reach IPv6 keep it. ([#337](https://github.com/full-bars/sn/pull/337), connect `cdd389a5e`)

**The extender activation request is no longer cut short** [redeploy]. The role's client strategy capped the activation request at fifteen seconds, below the sixty the activator asks for, so it was torn down mid-probe. The pinned `sdk` raises the cap to the activation budget. This is read from the commit and has not been observed in a live activation. (sdk `6f4d35ee3486`)

**`connect` and `sdk` pins moved** [redeploy]. `connect` from `d0a4bb41c300` to `ca8b9020201a`, `sdk` from `f17fc47e8bda` to `6f4d35ee3486`. (`12efc46ba`, `b1efe606d`)

## Tools

**A shared RAM log is streamed only by the provider that owns it** [redeploy]. `urnet-tools logs` could fall back to the shared `/dev/shm/urnetwork.log` when nothing else matched, so on a box with several providers it could show another provider's output. Ownership is now decided in one place, and a provider holding its own buffer is not treated as a rival for the shared one. ([#334](https://github.com/full-bars/sn/pull/334))

**User units are attached to their provider** [redeploy]. A provider run as a user unit with a free-form name such as `sn-canary.service` was never attached, because discovery vetted the cgroup unit by name. The owning user's manager decides now, and the user manager itself is no longer listed as a workload unit. When no log source can be found, the error now says which paths were checked. ([#335](https://github.com/full-bars/sn/pull/335))

**The help menus point at the community Discord** [redeploy]. (`cfa578c21`)

## Installers and container

**The FreeBSD installer reports a backup it could not remove** [redeploy]. After a good install, a failed removal of the old binary's backup was dropped silently. It now warns with the path of the copy left on disk. ([#338](https://github.com/full-bars/sn/pull/338))

**The nightly container updater takes the version from the release tag** [redeploy]. It scraped the version from an asset URL, so a URL not shaped like `/download/v<tag>/` went into `version.txt` whole and every check downloaded the archive again. The tag now comes from the release's `tag_name`, is reset on every check so a failed probe cannot reuse the previous release's tag, and an empty tag aborts the update. This is in `start_nightly.sh`, the `BUILD=nightly` path; the auth-code path in the sample above does not run it. ([#336](https://github.com/full-bars/sn/pull/336))

## CI and docs

**The release validator accepts the `full-bars/connect` replacement** [no redeploy]. Pinned dependency mode rejected the replacement `go.mod` now resolves to; the pinned module path, version and checksums are updated, along with the two tests that carry them. ([#337](https://github.com/full-bars/sn/pull/337), `25f427890`)

**Docs corrected against the code** [no redeploy]:

- `URNETWORK_NODE_NAME`, `URNETWORK_PROXY_BENCHMARK`, `URNETWORK_PROXY_BENCHMARK_ENDPOINT`, `URNETWORK_ADAPTIVE_GC` and `URNETWORK_SHM_LOG` are marked not implemented: no Go code in the tree reads them, so setting them changes nothing. Node labels, `urnet-tools rename` and `show-ip` are described the same way on the [Node Identity](https://github.com/full-bars/sn/blob/main/docs/Node-Identity.md) page.
- The Docker page now says vnStat is on by default (port 8080 unless `ENABLE_VNSTAT=false`) and that the Prometheus `/metrics` endpoint is on by default as a separate listener.
- The duplicate `urnet-tools-Go.md` page, which differed from `urnet-tools-go.md` only by case, is removed.
- The extender page and log reference describe the cause text on a failed activation, and the FreeBSD page states that durable client registration is refused there.
