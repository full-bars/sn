## Quick start

Already running a provider? Update it in place:

```sh
urnet-tools update
```

### Install a provider

```sh
# Linux, including Alpine and OpenRC
curl -fSsL https://raw.githubusercontent.com/full-bars/sn/refs/heads/main/scripts/Provider_Install_Linux.sh | sh

# macOS
curl -fSsL https://raw.githubusercontent.com/full-bars/sn/refs/heads/main/scripts/Provider_Install_Mac.sh | sh -s -- install
```

```powershell
irm https://raw.githubusercontent.com/full-bars/sn/refs/heads/main/scripts/Provider_Install_Win32.ps1 | iex
```

On FreeBSD, download the installer before running it with sudo:

```sh
fetch -qo urnet-install.sh https://raw.githubusercontent.com/full-bars/sn/refs/heads/main/scripts/Provider_Install_FreeBSD.sh
sudo sh urnet-install.sh install
```

Windows Defender can flag unsigned binaries. See [Installation](https://github.com/full-bars/sn/blob/main/docs/Installation.md).

### Run the container

```sh
docker run -d \
  --name meso-miner \
  --pull always \
  --restart unless-stopped \
  -e URNETWORK_AUTH_CODE='YOUR_AUTH_CODE_HERE' \
  -v meso_miner_data:/root/.urnetwork \
  ghcr.io/full-bars/sn:latest
```

Auth codes are single-use. Keep the state volume to retain the saved token. Existing installations should keep their existing volume name.

For an extender in a container, also publish `-p 443:443 -p 443:443/udp -p 4053:4053/udp` and provide the bind capability as described in the [extender guide](https://github.com/full-bars/sn/blob/main/docs/Extender.md). TCP 443 must be reachable from the internet. Publishing a container port does not configure a router or host firewall.

## What changed

### Extender

We added `urnet-tools extender status` and `urnet-tools extender setup` to inspect the role and prepare supported hosts. Status, `top` and metrics expose the role. Setup reports when it cannot verify a firewall or socket, warns when a systemd unit prevents the verified bind capability from taking effect, and tells Windows users when an elevated terminal is needed. It does not set a capability on a symlink or non-regular file. (#358)

We restored an existing bind capability after supported provider binary updates and installer swaps. A manual binary replacement can still drop the capability; run extender setup again after such a swap. (#365, #366)

We fixed carrier release during handover, guarded the slot releaser against replacement races, and stopped an undecided direct launch from holding proxy startup. The activation budget is rechecked as it becomes available. (#342; commits 40371e4b3, 9b056cccb, d32f696a7, d7634fc8f)

### Proxy traffic and health

We fixed client UDP for proxied identities. Each flow uses its proxy's verified SOCKS5 UDP relay. If the relay cannot be used, the flow is refused rather than sent from the host address. IPv6 destinations are refused because the relay check proves IPv4 only. Idle proxied UDP flows close after 120 seconds; direct flows retain their existing timeout. (#387, #388)

We made refresh preview include cached URL proxies. Parked proxies no longer count as degraded, and automatic degraded cleanup runs only when configured. Health output distinguishes held and parked slots. The direct slot is numbered zero; proxies start at one. (#379, #344, #348, #347, #343, #349, #369)

### State and identity

We protected fresh state directories against accidental replacement of a provider identity. Interactive starts ask for authority; unattended starts need an explicit allowing setting. Docker defaults to `auto`. Restore missing existing state rather than creating a replacement. (#378)

We hardened durable identity and settings recovery, saved legacy import proofs for reuse, and refuse a newer state-store schema instead of silently creating identities. The new migration and reconciliation primitives do not add operator migration commands. (#351, #357, #374, #376)

### Operations

We added `urnet-tools diag` to capture a running provider's heap and goroutine profiles, summary, and a CPU profile when available. Captures need at least 512 MiB free and can contain sensitive data. (#360)

We fixed Windows restart, stop and uninstall paths to check ownership and report failures instead of claiming success. We also made discovery warn and refuse unit-dependent actions when it cannot identify the owning service. macOS proxy maintenance wrappers now forward their arguments. (#384, #346, #367, #372)

We bounded shutdown recovery and moved the watchdog ahead of diagnostic capture. The memory-pressure cap now relaxes on demonstrated recovery. We also staggered network token renewal and reduced recurring sampling and state-write work. (#350, #352, #363, #341, #353, #375)

### CI and documentation

We made test shards run uncached and checked their test census. We strengthened smoke and soak assertions, isolated distro feature groups, and fixed intermittent tests. We updated the extender, installation, logging and feature-matrix documentation. (#381, #382, #383, #385, #386, #389)

Changes to provider or tools take effect after update and restart; CI and documentation changes do not require redeployment.

## [v2026.11.6-1091584480-sn] — <release date>

### Added

- **Capture diagnostics from a running provider.** `urnet-tools diag` writes heap and goroutine profiles, a summary and, when available, a 30-second CPU profile without a restart. The capture requires 512 MiB free and contains sensitive data. (#360, 30e7c6b40)
- **Inspect and configure the extender.** `urnet-tools extender status` reports the running role and `extender setup` checks the host and configures supported binding and firewall requirements. `top` and metrics expose its state. (#358, #340)
- **The state store has migration and reconciliation primitives.** S1 adds inert migration records and a non-mutating file/store comparison; it does not add operator migration commands. (#376)
- **Persist legacy identity proofs.** The miner saves proofs and adopts them on restart, while re-proving revoked identities and retaining custody through fallback. (#351)

### Fixed

- **Extender setup handles incomplete host checks.** Unverifiable socket or firewall checks produce guidance instead of aborting setup. A systemd unit that blocks the file capability gets a warning. FreeBSD ignores commented sysctl settings, Linux refuses to set capabilities on symlinks or non-regular files, and Windows names the need for an elevated terminal. (c67ba09db, e9cc68504, 079b5b73c, 066102eb3, 720c45914, f2d6c32a1)
- **Extender handover releases the right resources.** The baton path releases carrier ports, an old slot cannot clear its replacement's releaser, and an undecided direct launch ends its head start. (40371e4b3, 9b056cccb, d32f696a7)
- **Windows lifecycle operations fail closed.** Restart, stop and uninstall check process and service ownership, and report failures rather than leaving an unmanaged supervisor or claiming success. (#384)
- **A fresh state directory needs authority to create the provider identity.** Interactive start asks. A direct unattended `provide` needs the registration flag or an allowing environment setting. Docker defaults to `auto`, which permits registration without a prompt. Restore missing existing state instead of allocating a replacement. (#378)
- **Refresh preview includes cached URL proxies.** It uses the manager's desired-set read so the preview reflects the same cached inputs as refresh. (#379)
- **Updates restore extender bind capability.** The Go update path reapplies a previously held capability after replacing the binary. The Linux installer and container wrappers also restore it after a swap when possible. (#365, #366)
- **Proxied client UDP uses the proxy relay.** Each flow uses its own SOCKS5 UDP association; a failed relay check refuses the flow rather than falling back to the host. IPv6 destinations are refused because the check only proves IPv4. Idle proxied flows close after 120 seconds; direct flows keep their 300-second default. (#387, #388)
- **State recovery preserves identities and settings.** Extender identity is durable, conflicting migrations are recorded once, stale recovery backups are cleared and the provider-key census streams on supported platforms. Newer state-store schemas refuse startup rather than minting identities. (#374, #357)
- **Extender setup handles platform failures.** It verifies binding in the provider context, repairs Windows firewall rules and handles a missing FreeBSD sysctl configuration. (#368)
- **Discovery and actions fail safely on incomplete scans.** Status and top remain responsive, show warnings and refuse unit-dependent actions when the owning service cannot be found. (#346, #367)
- **The direct slot is numbered zero.** Proxy slots begin at one. (#369)
- **macOS forwards proxy maintenance arguments.** Refresh and remove-dead receive the arguments passed to the wrapper. (#372)
- **Unhealthy URL proxies retire only when cleanup is configured.** Parked proxies are no longer counted as degraded and pool health counts admitted proxies. (#344, #348, #347)
- **Shutdown and memory pressure recovery are bounded.** The shutdown watchdog starts before the dump and retains the quarantine exit code; the thrash cap relaxes only on demonstrated health. (#363, #350, #352)
- **Extender startup and handover recover faster.** Carrier ports are released before replacement, activation budget availability is rechecked, and the direct slot gets a short head start. (#342, 58454832b, d7634fc8f)

### Changed

- **Private settings and counters can move into the state store.** Schema stamps prevent older builds from silently consuming newer state; file fallback remains when the store is unavailable. (#357)
- **Control snapshots and state writes avoid redundant work.** Snapshots are cached briefly, invalidated on control changes and unchanged records skip writes. (#375)
- **Network token renewal is staggered.** Renewal is drawn within 40 to 50 percent of token lifetime; a token without a usable issue time renews immediately. (#341)
- **Per-slot billing and transport sampling share a ticker.** This removes one recurring loop per proxied slot. (#353)
- **Connect and SDK pins follow their fork mains.** The updates carry extender and networking changes. (#339, #354, #364, #371, #373)
- **The trim cancel path is findable and previewable.** `urnet-tools proxy trim` shows how to cancel a cut and previews it before it applies. (#345)
- **Proxy health and discovery output is clearer.** Held and parked slots are reported separately and `top` shows discovery warnings. (#343, #349, #362)

### CI and documentation

- **Test shards gate on uncached results and test census.** Distro feature groups use independent state and randomized ordering; smoke and soak checks have stronger assertions. Intermittent miner tests were corrected. (#381, #382, #383, #385, #386, #389)
- **Windows installation guidance and SN25 figures were refreshed.** (#384, bcd070848)
